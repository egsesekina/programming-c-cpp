### Задание 49. Кратчайший путь в матрице

**Условие.** Найти BFS минимальное число шагов в матрице препятствий.

#### Формат входных данных

R C (1..1000), затем ровно R*C значений 0 или 1.

#### Формат выходных данных

длина пути от (0,0) до (R-1,C-1) либо -1. Если входные данные нарушают указанный формат или ограничения, программа выводит `Error` в стандартный поток ошибок и завершается с ненулевым кодом.

#### Разбор решения

BFS посещает невзвешенную сетку слоями расстояния. Расстояние записывается до помещения клетки в очередь, поэтому каждая клетка попадает в очередь не более одного раза и цикл всегда завершается.

#### Алгоритм

1. проверить размеры и все клетки.
2. отклонить заблокированный старт или финиш.
3. запустить BFS по четырём направлениям.
4. вывести расстояние до финиша.

#### Исходный код

[main.cpp](main.cpp)

```cpp
/*
 * Задание 49. Найти BFS минимальное число шагов в матрице препятствий.
 * Ввод: R C (1..1000), затем ровно R*C значений 0 или 1.
 * Вывод: длина пути от (0,0) до (R-1,C-1) либо -1.
 * Пример: 2 2 / 0 0 / 1 0 -> 2.
 */
#include <array>
#include <iostream>
#include <queue>
#include <utility>
#include <vector>

using namespace std;

int main() {
    int rows, cols;
    if (!(cin >> rows >> cols) || rows <= 0 || rows > 1000 ||
        cols <= 0 || cols > 1000) {
        cerr << "Error\n";
        return 1;
    }

    vector<vector<int>> grid(rows, vector<int>(cols));
    for (auto& row : grid) {
        for (int& cell : row) {
            if (!(cin >> cell) || (cell != 0 && cell != 1)) {
                cerr << "Error\n";
                return 1;
            }
        }
    }

    if (grid[0][0] == 1 || grid[rows - 1][cols - 1] == 1) {
        cout << -1 << '\n';
        return 0;
    }

    vector<vector<int>> dist(rows, vector<int>(cols, -1));
    queue<pair<int, int>> q;
    q.push({0, 0});
    dist[0][0] = 0;

    const array<int, 4> dr = {-1, 1, 0, 0};
    const array<int, 4> dc = {0, 0, -1, 1};

    // BFS находит кратчайший путь в невзвешенной сетке.
    while (!q.empty()) {
        auto [r, c] = q.front();
        q.pop();
        for (int k = 0; k < 4; ++k) {
            int nr = r + dr[k], nc = c + dc[k];
            if (nr < 0 || nr >= rows || nc < 0 || nc >= cols) continue;
            if (grid[nr][nc] == 1 || dist[nr][nc] != -1) continue;
            dist[nr][nc] = dist[r][c] + 1;
            q.push({nr, nc});
        }
    }
    cout << dist[rows - 1][cols - 1] << '\n';
    return 0;
}

```

#### Пример работы

Ввод:

```text
2 2
0 0
1 0
```

Вывод:

```text
2
```

#### Граничные случаи

Если вход содержит меньше `R*C` клеток, программа завершает чтение с `Error`; это не бесконечный цикл. Заблокированные концы и отсутствие пути дают `-1`.

#### Компиляция и запуск

```bash
g++ -std=c++17 -Wall -Wextra -Wpedantic main.cpp -o program
./program
```
