### Задание 1. Этапы получения исполняемой программы

**Вопрос.** В каком порядке обычно выполняются основные этапы получения исполняемой программы из исходного файла на C?

- A) компоновка → препроцессор → компиляция
- Б) препроцессор → компиляция → компоновка
- В) компиляция → компоновка → препроцессор
- Г) интерпретация → компоновка → компиляция

**Правильный ответ:** Б) препроцессор → компиляция → компоновка.

**Обоснование:** препроцессор раскрывает директивы `#include`, `#define` и условную компиляцию. Затем компилятор переводит подготовленный текст программы в объектный код. Компоновщик объединяет объектные файлы и библиотеки и формирует исполняемый файл.

**Почему остальные варианты неверны:**

- компоновка не может выполняться до появления объектных файлов;
- препроцессор должен обработать директивы до компиляции;
- стандартный процесс сборки программы на C не требует интерпретатора.
