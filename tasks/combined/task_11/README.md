### Задание 11. Наследование

**Вопрос.** Какое ключевое слово используется для объявления виртуальной функции в базовом классе?

- A) `virtual`
- Б) `friend`
- В) `namespace`
- Г) `typedef`

**Правильный ответ:** A) `virtual`.

**Объяснение:** виртуальные функции обеспечивают динамический полиморфизм при вызове через указатель или ссылку на базовый класс.
