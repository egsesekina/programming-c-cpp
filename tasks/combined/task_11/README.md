### Задание 11. Виртуальные функции

#### Теоретическая часть

**Вопрос.** Какое ключевое слово объявляет виртуальную функцию базового класса? Выберите ответ и объясните свой выбор.

- A) `virtual`
- Б) `friend`
- В) `namespace`
- Г) `typedef`

**Правильный ответ:** A) `virtual`.

**Эталонное объяснение:** `virtual` включает динамический выбор переопределённого метода. `friend` предоставляет доступ, `namespace` создаёт пространство имён, `typedef` задаёт псевдоним типа. В производном классе полезно писать `override`, чтобы компилятор проверил точность переопределения.

#### Практическая часть

**Условие.** Напишите базовый интерфейс `Operation`, производный класс удвоения и вызовите метод через ссылку на базовый класс.

**Формат входных данных:** Одно целое число от -1000000000 до 1000000000.

**Формат выходных данных:** Удвоенное значение. При нарушении формата программа выводит `Error` в стандартный поток ошибок и завершается с ненулевым кодом.

**Разбор решения:** Ссылка имеет тип базового класса, но виртуальный вызов выбирает `DoubleOperation::apply`.

**Алгоритм:**

1. считать и проверить значение.
2. создать производный объект.
3. связать с ним ссылку базового типа.
4. вызвать виртуальный метод и вывести результат.

**Исходный код:** [main.cpp](main.cpp)

```cpp
/*
 * Задание 11. Показать динамический полиморфизм через virtual и override.
 * Ввод: целое число.
 * Вывод: удвоенное число через вызов виртуального метода.
 * Пример: 7 -> 14.
 */
#include <iostream>

class Operation {
public:
    virtual int apply(int value) const = 0;
    virtual ~Operation() = default;
};

class DoubleOperation final : public Operation {
public:
    int apply(int value) const override { return value * 2; }
};

int main() {
    int value;
    if (!(std::cin >> value) || value < -1000000000 || value > 1000000000) {
        std::cerr << "Error\n";
        return 1;
    }
    const DoubleOperation operation;
    const Operation& base = operation;
    std::cout << base.apply(value) << '\n';
    return 0;
}

```

**Пример входных данных:**

```text
7
```

**Пример выходных данных:**

```text
14
```

**Граничные случаи:** Диапазон исключает переполнение при удвоении.

**Компиляция и запуск:**

```bash
g++ -std=c++17 -Wall -Wextra -Wpedantic main.cpp -o program
./program
```
