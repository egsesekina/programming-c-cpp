### Задание 6. Анализ и исправление цикла

#### Теоретическая часть

**Вопрос.** Какой цикл корректно выводит числа от 1 до 5 включительно? Выберите ответ и объясните свой выбор.

- A) `for (int i = 1; i < 5; ++i)`
- Б) `for (int i = 1; i <= 5; ++i)`
- В) `for (int i = 1; i <= 6; --i)`
- Г) `for (int i = 1; i = 5; ++i)`

**Правильный ответ:** Б.

**Эталонное объяснение:** Вариант Б начинает с 1, допускает значение 5 и увеличивает счётчик. Вариант A останавливается перед 5. В варианте В счётчик уменьшается; после ухода в отрицательные значения он в конечном итоге переполнит знаковый `int`, что является неопределённым поведением, поэтому называть этот цикл просто бесконечным неточно. Вариант Г выполняет присваивание в условии; оно каждый раз даёт истинное значение 5, а затем тело получает `i == 5`.

#### Практическая часть

**Условие.** Напишите исправленную программу, которая считывает `N` и выводит числа от 1 до `N` включительно.

**Формат входных данных:** Целое `N` от 1 до 1000.

**Формат выходных данных:** Последовательность `1 2 ... N`. При нарушении формата программа выводит `Error` в стандартный поток ошибок и завершается с ненулевым кодом.

**Разбор решения:** Счётчик растёт на единицу, а условие `i <= n` включает правую границу.

**Алгоритм:**

1. считать и проверить `N`.
2. инициализировать `i` единицей.
3. пока `i <= N`, вывести `i`.
4. увеличить `i`.

**Исходный код:** [main.cpp](main.cpp)

```cpp
/*
 * Задание 6. Реализовать исправленный цикл, выводящий числа от 1 до N.
 * Ввод: N от 1 до 1000.
 * Вывод: числа 1..N через пробел.
 * Пример: 5 -> 1 2 3 4 5.
 */
#include <iostream>

int main() {
    int n;
    if (!(std::cin >> n) || n < 1 || n > 1000) {
        std::cerr << "Error\n";
        return 1;
    }
    for (int i = 1; i <= n; ++i) {
        std::cout << i << (i == n ? '\n' : ' ');
    }
    return 0;
}

```

**Пример входных данных:**

```text
5
```

**Пример выходных данных:**

```text
1 2 3 4 5
```

**Граничные случаи:** Значения вне диапазона и неверный формат дают `Error`.

**Компиляция и запуск:**

```bash
g++ -std=c++17 -Wall -Wextra -Wpedantic main.cpp -o program
./program
```
