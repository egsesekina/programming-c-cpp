Задание 6. Исправление цикла
Какой вариант корректно выводит числа от 1 до 5 включительно?
А) for (int i = 1; i < 5; ++i)
Б) for (int i = 1; i <= 5; ++i)
В) for (int i = 1; i <= 5; --i)
Г) for (int i = 1; i = 5; ++i)
Правильный ответ: Б.
Объяснение: Условие i <= 5 включает число 5, а ++i увеличивает счётчик. Вариант А не выводит 5; вариант В не завершается при обычном выполнении; вариант Г использует присваивание вместо сравнения.
