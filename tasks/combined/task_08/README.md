### Задание 8. Передача аргументов в функцию

**Вопрос.** Какой вариант передаёт объект типа `int` так, чтобы функция могла изменить исходную переменную?

- A) `void change(int x)`
- Б) `void change(const int x)`
- В) `void change(int& x)`
- Г) `void change(int x, int y)`

**Правильный ответ:** В) `void change(int& x)`.

**Объяснение:** ссылка связывает параметр с исходной переменной, поэтому изменение параметра меняет исходное значение.

**Листинг программы:**

```cpp
#include <iostream>

// Аргумент передаётся по ссылке.
void increment(int& value) {
    ++value;
}

int main() {
    int number = 10;
    increment(number);
    std::cout << number << '\n'; // 11
    return 0;
}
```

**Дополнительная часть:** реализовать функцию, увеличивающую переданное число на единицу.
