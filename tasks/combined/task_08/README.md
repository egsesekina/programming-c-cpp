### Задание 8. Передача аргумента по ссылке

#### Теоретическая часть

**Вопрос.** Какая сигнатура позволяет функции изменить исходную переменную типа `int`? Выберите ответ и объясните свой выбор.

- A) `void change(int x)`
- Б) `void change(const int x)`
- В) `void change(int& x)`
- Г) `void change(int x, int y)`

**Правильный ответ:** В) `void change(int& x)`.

**Эталонное объяснение:** Неконстантная ссылка связывает параметр с исходным объектом. Варианты A и Б передают копию; `const` в Б запрещает менять даже копию. Вариант Г также принимает копии и отличается только числом параметров.

#### Практическая часть

**Условие.** Напишите функцию `increment(int&)` и программу, которая считывает число, увеличивает исходную переменную и выводит результат.

**Формат входных данных:** Одно значение `int`, меньшее `INT_MAX`.

**Формат выходных данных:** Увеличенное на единицу число. При нарушении формата программа выводит `Error` в стандартный поток ошибок и завершается с ненулевым кодом.

**Разбор решения:** Функция изменяет объект вызывающего кода через ссылку. Значение `INT_MAX` заранее отклоняется, чтобы не допустить знакового переполнения.

**Алгоритм:**

1. считать и проверить число.
2. передать его в `increment` по ссылке.
3. увеличить значение внутри функции.
4. вывести изменённую переменную.

**Исходный код:** [main.cpp](main.cpp)

```cpp
/*
 * Задание 8. Изменить исходную переменную через ссылочный параметр.
 * Ввод: одно целое число меньше INT_MAX.
 * Вывод: число, увеличенное на единицу.
 * Пример: 10 -> 11.
 */
#include <climits>
#include <iostream>

void increment(int& value) {
    ++value;
}

int main() {
    int number;
    if (!(std::cin >> number) || number == INT_MAX) {
        std::cerr << "Error\n";
        return 1;
    }
    increment(number);
    std::cout << number << '\n';
    return 0;
}

```

**Пример входных данных:**

```text
10
```

**Пример выходных данных:**

```text
11
```

**Граничные случаи:** Для `INT_MAX` программа выводит `Error`.

**Компиляция и запуск:**

```bash
g++ -std=c++17 -Wall -Wextra -Wpedantic main.cpp -o program
./program
```
