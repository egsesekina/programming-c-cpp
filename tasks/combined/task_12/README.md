### Задание 12. Обработка исключений

#### Теоретическая часть

**Вопрос.** Какой блок выполняется при перехвате подходящего исключения? Выберите ответ и объясните свой выбор.

- A) `try`
- Б) `catch`
- В) `throw`
- Г) `finally`

**Правильный ответ:** Б) `catch`.

**Эталонное объяснение:** `try` ограничивает защищаемый участок, `throw` создаёт исключительную ситуацию, а подходящий `catch` её обрабатывает. Стандартный C++ не имеет блока `finally`; освобождение ресурсов обычно обеспечивает RAII.

#### Практическая часть

**Условие.** Напишите функцию целочисленного деления, которая выбрасывает исключение при нулевом делителе, и обработайте исключение в `main`.

**Формат входных данных:** Два значения `int`.

**Формат выходных данных:** Частное либо `Error`. При нарушении формата программа выводит `Error` в стандартный поток ошибок и завершается с ненулевым кодом.

**Разбор решения:** Функция проверяет нулевой делитель и единственный переполняющий случай `INT_MIN / -1`, после чего выполняет деление.

**Алгоритм:**

1. считать два числа.
2. вызвать функцию внутри `try`.
3. в функции проверить ошибочные случаи.
4. вывести частное либо обработать исключение в `catch`.

**Исходный код:** [main.cpp](main.cpp)

```cpp
/*
 * Задание 12. Выполнить целочисленное деление и обработать нулевой делитель.
 * Ввод: два целых числа.
 * Вывод: частное либо Error при нулевом делителе.
 * Пример: 12 3 -> 4.
 */
#include <climits>
#include <iostream>
#include <stdexcept>

int divide(int numerator, int denominator) {
    if (denominator == 0) throw std::invalid_argument("division by zero");
    if (numerator == INT_MIN && denominator == -1) {
        throw std::overflow_error("integer overflow");
    }
    return numerator / denominator;
}

int main() {
    int numerator, denominator;
    if (!(std::cin >> numerator >> denominator)) {
        std::cerr << "Error\n";
        return 1;
    }
    try {
        std::cout << divide(numerator, denominator) << '\n';
    } catch (const std::exception&) {
        std::cerr << "Error\n";
        return 1;
    }
    return 0;
}

```

**Пример входных данных:**

```text
12 3
```

**Пример выходных данных:**

```text
4
```

**Граничные случаи:** Нулевой делитель и `INT_MIN / -1` дают `Error`.

**Компиляция и запуск:**

```bash
g++ -std=c++17 -Wall -Wextra -Wpedantic main.cpp -o program
./program
```
