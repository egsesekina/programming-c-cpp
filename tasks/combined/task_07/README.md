### Задание 7. Работа со строками

**Вопрос.** Какой заголовочный файл нужен для использования `std::string`?

- A) `<cmath>`
- Б) `<string>`
- В) `<fstream>`
- Г) `<cstdlib>`

**Правильный ответ:** Б) `<string>`.

**Объяснение:** класс `std::string` объявлен в заголовочном файле `<string>`.

**Листинг программы:**

```cpp
#include <iostream>
#include <string>

int main() {
    std::string text;
    // Считываем всю строку, включая пробелы.
    std::getline(std::cin, text);
    std::cout << text.size() << '\n';
    return 0;
}
```

**Дополнительная часть:** программа считывает строку целиком и выводит её длину.
