### Задание 10. Автоматическое управление динамической памятью

#### Теоретическая часть

**Вопрос.** Какой способ предпочтителен для единоличного владения динамическим объектом в современном C++? Выберите ответ и объясните свой выбор.

- A) `new` без освобождения
- Б) `std::unique_ptr` из `<memory>`
- В) глобальный сырой указатель
- Г) `free` для объекта, созданного через `new`

**Правильный ответ:** Б) `std::unique_ptr`.

**Эталонное объяснение:** `std::unique_ptr` освобождает объект при выходе из области видимости и выражает единоличное владение. Вариант A создаёт утечку, В скрывает владельца и усложняет время жизни, Г смешивает несовместимые механизмы выделения и освобождения и приводит к неопределённому поведению.

#### Практическая часть

**Условие.** Напишите программу, которая создаёт динамический массив через `std::unique_ptr<int[]>`, считывает элементы и выводит сумму.

**Формат входных данных:** `N` от 1 до 100000, затем `N` целых чисел.

**Формат выходных данных:** Сумма элементов типа `long long`. При нарушении формата программа выводит `Error` в стандартный поток ошибок и завершается с ненулевым кодом.

**Разбор решения:** Владеющий умный указатель освобождает массив автоматически на любом пути выхода из `main`.

**Алгоритм:**

1. считать и проверить `N`.
2. создать `unique_ptr<int[]>`.
3. считать элементы и накопить сумму.
4. вывести сумму.

**Исходный код:** [main.cpp](main.cpp)

```cpp
/*
 * Задание 10. Управлять динамическим массивом с помощью unique_ptr.
 * Ввод: N (1..100000), затем N целых чисел.
 * Вывод: сумма элементов.
 * Пример: 4 / 1 2 3 4 -> 10.
 */
#include <iostream>
#include <memory>

int main() {
    int n;
    if (!(std::cin >> n) || n < 1 || n > 100000) {
        std::cerr << "Error\n";
        return 1;
    }
    auto values = std::make_unique<int[]>(static_cast<std::size_t>(n));
    long long sum = 0;
    for (int i = 0; i < n; ++i) {
        if (!(std::cin >> values[i])) {
            std::cerr << "Error\n";
            return 1;
        }
        sum += values[i];
    }
    std::cout << sum << '\n';
    return 0;
}

```

**Пример входных данных:**

```text
4
1 2 3 4
```

**Пример выходных данных:**

```text
10
```

**Граничные случаи:** Ошибочный или неполный ввод даёт `Error`; отдельный `delete[]` не нужен.

**Компиляция и запуск:**

```bash
g++ -std=c++17 -Wall -Wextra -Wpedantic main.cpp -o program
./program
```
