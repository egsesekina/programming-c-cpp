### Задание 10. Динамическая память

**Вопрос.** Какой способ предпочтителен в современном C++ для автоматического управления динамической памятью?

- A) Использовать `new` без освобождения памяти.
- Б) Использовать `std::unique_ptr` из `<memory>`.
- В) Использовать глобальные указатели для всех объектов.
- Г) Освобождать любой объект через `free` независимо от способа выделения.

**Правильный ответ:** Б) `std::unique_ptr`.

**Объяснение:** умный указатель автоматически освобождает принадлежащий ему объект при завершении времени жизни.
