### Задание 10. Обработка исключений

**Вопрос.** Какой блок выполняется при перехвате подходящего исключения?

- A) `try`
- Б) `catch`
- В) `throw`
- Г) `finally`

**Правильный ответ:** Б) `catch`.

**Объяснение:** `try` содержит потенциально опасный код, `throw` выбрасывает исключение, `catch` обрабатывает подходящее исключение.
