### Задание 5. Целочисленное и вещественное деление

#### Теоретическая часть

**Вопрос.** Что выведет выражение `7 / 2`, если оба операнда имеют тип `int`? Выберите ответ и объясните свой выбор.

- A) `3.5`
- Б) `3`
- В) `4`
- Г) ошибка компиляции

**Правильный ответ:** Б) `3`.

**Эталонное объяснение:** Оба операнда имеют тип `int`, поэтому дробная часть результата отбрасывается. Вариант A получился бы после преобразования хотя бы одного операнда в вещественный тип. Вариант В предполагает округление, которого целочисленное деление не выполняет. Вариант Г неверен: выражение корректно.

#### Практическая часть

**Условие.** Напишите программу, которая считывает два целых числа и выводит сначала результат целочисленного деления, затем вещественное частное.

**Формат входных данных:** Два целых числа; второе не равно нулю.

**Формат выходных данных:** Два результата на отдельных строках. При нарушении формата программа выводит `Error` в стандартный поток ошибок и завершается с ненулевым кодом.

**Разбор решения:** Для второго результата левый операнд явно преобразуется в `double`. Проверка делителя выполняется до обеих операций.

**Алгоритм:**

1. считать два числа и проверить делитель.
2. вывести целочисленное частное.
3. преобразовать левый операнд в `double`.
4. вывести вещественное частное.

**Исходный код:** [main.cpp](main.cpp)

```cpp
/*
 * Задание 5. Сравнить целочисленное и вещественное деление.
 * Ввод: два целых числа, второе не равно нулю.
 * Вывод: целая часть частного и точное частное типа double.
 * Пример: 7 2 -> 3 / 3.5.
 */
#include <iostream>

int main() {
    int left, right;
    if (!(std::cin >> left >> right) || right == 0) {
        std::cerr << "Error\n";
        return 1;
    }
    std::cout << left / right << '\n'
              << static_cast<double>(left) / right << '\n';
    return 0;
}

```

**Пример входных данных:**

```text
7 2
```

**Пример выходных данных:**

```text
3
3.5
```

**Граничные случаи:** Нулевой делитель даёт `Error`; знак результата определяется правилами деления C++.

**Компиляция и запуск:**

```bash
g++ -std=c++17 -Wall -Wextra -Wpedantic main.cpp -o program
./program
```
