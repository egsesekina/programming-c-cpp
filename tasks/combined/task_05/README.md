### Задание 5. Результат выполнения программы

**Вопрос.** Что выведет программа?

```cpp
#include <iostream>

int main() {
    int x = 7;
    std::cout << x / 2;
    return 0;
}
```

- A) `3.5`
- Б) `3`
- В) `4`
- Г) Ошибка компиляции.

**Правильный ответ:** Б) `3`.

**Объяснение:** оба операнда имеют тип `int`, поэтому выполняется целочисленное деление.
