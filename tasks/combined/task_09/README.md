### Задание 9. Указатели и массивы

#### Теоретическая часть

**Вопрос.** Что означает `*(arr + 2)`, если `arr` указывает на первый элемент массива? Выберите ответ и объясните свой выбор.

- A) адрес первого элемента
- Б) значение третьего элемента
- В) размер массива
- Г) значение второго элемента

**Правильный ответ:** Б) значение третьего элемента.

**Эталонное объяснение:** Смещение `arr + 2` указывает на элемент с индексом 2, а разыменование возвращает его значение. Вариант A описывает `arr`, вариант В невозможно получить из обычного указателя, вариант Г соответствовал бы `*(arr + 1)`.

#### Практическая часть

**Условие.** Напишите программу, которая считывает пять чисел и получает третий элемент только через арифметику указателей.

**Формат входных данных:** Пять целых чисел.

**Формат выходных данных:** Третье введённое число. При нарушении формата программа выводит `Error` в стандартный поток ошибок и завершается с ненулевым кодом.

**Разбор решения:** Имя массива преобразуется в указатель на первый элемент; прибавление 2 учитывает размер типа `int` автоматически.

**Алгоритм:**

1. считать пять элементов.
2. получить указатель на первый элемент.
3. сместить указатель на два элемента.
4. разыменовать и вывести результат.

**Исходный код:** [main.cpp](main.cpp)

```cpp
/*
 * Задание 9. Получить третий элемент массива арифметикой указателей.
 * Ввод: пять целых чисел.
 * Вывод: третий элемент.
 * Пример: 4 8 15 16 23 -> 15.
 */
#include <iostream>

int main() {
    int values[5];
    for (int& value : values) {
        if (!(std::cin >> value)) {
            std::cerr << "Error\n";
            return 1;
        }
    }
    const int* first = values;
    std::cout << *(first + 2) << '\n';
    return 0;
}

```

**Пример входных данных:**

```text
4 8 15 16 23
```

**Пример выходных данных:**

```text
15
```

**Граничные случаи:** Неполный или нечисловой ввод даёт `Error`.

**Компиляция и запуск:**

```bash
g++ -std=c++17 -Wall -Wextra -Wpedantic main.cpp -o program
./program
```
