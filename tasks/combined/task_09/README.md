### Задание 9. Указатели и массивы

**Вопрос.** Что означает выражение `*(arr + 2)`, если `arr` — указатель на первый элемент массива?

- A) Адрес первого элемента.
- Б) Значение третьего элемента.
- В) Размер массива.
- Г) Значение второго элемента.

**Правильный ответ:** Б) Значение третьего элемента.

**Объяснение:** смещение на два элемента и разыменование дают элемент с индексом 2.
