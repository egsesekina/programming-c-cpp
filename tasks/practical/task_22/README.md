### Задание 22. Условный оператор

**Вопрос.** Определите, является ли целое число чётным или нечётным.

**Правильный ответ:** программа должна выводить результат, соответствующий условию задачи.

**Листинг программы:**

```cpp
#include <iostream>

int main() {
    long long n;
    std::cin >> n;
    if (n % 2 == 0) {
        std::cout << "Even\n";
    } else {
        std::cout << "Odd\n";
    }
    return 0;
}
```
