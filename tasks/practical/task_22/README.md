### Задание 22. Динамическая память в C

**Условие.** Выделить динамический массив через malloc, считать его, вывести элементы в обратном порядке и освободить память через free.

#### Формат входных данных

N (1..100000), затем N целых чисел.

#### Формат выходных данных

элементы в обратном порядке. Если входные данные нарушают указанный формат или ограничения, программа выводит `Error` в стандартный поток ошибок и завершается с ненулевым кодом.

#### Разбор решения

Размер массива становится известен во время выполнения, поэтому память выделяется через `malloc`. Единственный владеющий указатель освобождается через `free` как при успехе, так и при ошибке чтения.

#### Алгоритм

1. проверить размер.
2. выделить память.
3. считать элементы с обработкой ошибки.
4. вывести их с конца и освободить память.

#### Исходный код

[main.c](main.c)

```c
/*
 * Задание 22. Выделить динамический массив через malloc, считать его,
 * вывести элементы в обратном порядке и освободить память через free.
 * Ввод: N (1..100000), затем N целых чисел.
 * Вывод: элементы в обратном порядке.
 * Пример: 4 / 10 20 30 40 -> 40 30 20 10.
 */
#include <stdio.h>
#include <stdlib.h>

int main(void) {
    int n;
    if (scanf("%d", &n) != 1 || n < 1 || n > 100000) {
        fprintf(stderr, "Error\n");
        return 1;
    }

    int *values = malloc((size_t)n * sizeof(*values));
    if (values == NULL) {
        fprintf(stderr, "Error\n");
        return 1;
    }

    for (int i = 0; i < n; ++i) {
        if (scanf("%d", &values[i]) != 1) {
            free(values);
            fprintf(stderr, "Error\n");
            return 1;
        }
    }

    for (int i = n - 1; i >= 0; --i) {
        printf("%d%c", values[i], i == 0 ? '\n' : ' ');
    }
    free(values);
    return 0;
}

```

#### Пример работы

Ввод:

```text
4
10 20 30 40
```

Вывод:

```text
40 30 20 10
```

#### Граничные случаи

При неполном вводе память освобождается до завершения программы; нулевой и чрезмерный размер отклоняются.

#### Компиляция и запуск

```bash
gcc -std=c17 -Wall -Wextra -Wpedantic main.c -o program
./program
```
