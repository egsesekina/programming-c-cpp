### Задание 44. Перегрузка функций

**Условие.** Перегрузить функцию maxValue для двух и трёх аргументов.

#### Формат входных данных

отсутствует.

#### Формат выходных данных

7 и 7 на отдельных строках. Если входные данные нарушают указанный формат или ограничения, программа выводит `Error` в стандартный поток ошибок и завершается с ненулевым кодом.

#### Разбор решения

Компилятор выбирает перегрузку по числу аргументов. Версия для трёх значений повторно использует двухаргументную функцию и не дублирует сравнение.

#### Алгоритм

1. вызвать двухаргументную перегрузку.
2. вызвать трёхаргументную перегрузку.
3. вывести оба результата.

#### Исходный код

[main.cpp](main.cpp)

```cpp
/*
 * Задание 44. Перегрузить функцию maxValue для двух и трёх аргументов.
 * Ввод: отсутствует.
 * Вывод: 7 и 7 на отдельных строках.
 * Пример запуска: program -> 7 / 7.
 */
#include <algorithm>
#include <iostream>

int maxValue(int a, int b) {
    return a > b ? a : b;
}

int maxValue(int a, int b, int c) {
    return std::max(maxValue(a, b), c);
}

int main() {
    std::cout << maxValue(4, 7) << '\n';
    std::cout << maxValue(4, 7, 2) << '\n';
    return 0;
}

```

#### Пример работы

Ввод:

```text
не требуется
```

Вывод:

```text
7
7
```

#### Граничные случаи

При равных значениях возвращается одно из равных значений; ввод не требуется.

#### Компиляция и запуск

```bash
g++ -std=c++17 -Wall -Wextra -Wpedantic main.cpp -o program
./program
```
