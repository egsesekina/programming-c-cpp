### Задание 44. Перегрузка функций

**Условие.** Перегрузить функцию maxValue для двух и трёх аргументов.

#### Формат входных данных

три целых числа.

#### Формат выходных данных

максимум первых двух чисел и максимум всех трёх чисел на отдельных строках. Если входные данные нарушают указанный формат, программа выводит `Error` в стандартный поток ошибок и завершается с ненулевым кодом.

#### Разбор решения

Компилятор выбирает перегрузку по числу аргументов. Версия для трёх значений повторно использует двухаргументную функцию и не дублирует сравнение.

#### Алгоритм

1. считать три числа.
2. вызвать двухаргументную перегрузку для первых двух чисел.
3. вызвать трёхаргументную перегрузку для всех чисел.
4. вывести оба результата.

#### Исходный код

[main.cpp](main.cpp)

```cpp
/*
 * Задание 44. Перегрузить функцию maxValue для двух и трёх аргументов.
 * Ввод: три целых числа.
 * Вывод: максимум первых двух и максимум всех трёх чисел.
 * Пример: 4 7 2 -> 7 / 7.
 */
#include <algorithm>
#include <iostream>

long long maxValue(long long a, long long b) {
    return a > b ? a : b;
}

long long maxValue(long long a, long long b, long long c) {
    return std::max(maxValue(a, b), c);
}

int main() {
    long long a, b, c;
    if (!(std::cin >> a >> b >> c)) {
        std::cerr << "Error\n";
        return 1;
    }
    std::cout << maxValue(a, b) << '\n';
    std::cout << maxValue(a, b, c) << '\n';
    return 0;
}

```

#### Пример работы

Ввод:

```text
4 7 2
```

Вывод:

```text
7
7
```

#### Граничные случаи

При равных значениях возвращается одно из равных значений; отрицательные числа обрабатываются без особого случая.

#### Компиляция и запуск

```bash
g++ -std=c++17 -Wall -Wextra -Wpedantic main.cpp -o program
./program
```
