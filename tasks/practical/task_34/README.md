### Задание 34. Подсчёт чётных элементов

**Условие.** Подсчитать чётные элементы массива.

#### Формат входных данных

N (1..1000), затем N целых чисел.

#### Формат выходных данных

количество чётных элементов. Если входные данные нарушают указанный формат или ограничения, программа выводит `Error` в стандартный поток ошибок и завершается с ненулевым кодом.

#### Разбор решения

Каждый элемент читается один раз. Остаток от деления на два равен нулю для чётных положительных, отрицательных чисел и нуля.

#### Алгоритм

1. проверить размер.
2. читать элементы по одному.
3. увеличивать счётчик при нулевом остатке.
4. вывести счётчик.

#### Исходный код

[main.cpp](main.cpp)

```cpp
/*
 * Задание 34. Подсчитать чётные элементы массива.
 * Ввод: N (1..1000), затем N целых чисел.
 * Вывод: количество чётных элементов.
 * Пример: 5 / 1 2 4 7 8 -> 3.
 */
#include <iostream>

int main() {
    int n;
    if (!(std::cin >> n) || n < 1 || n > 1000) {
        std::cerr << "Error\n";
        return 1;
    }
    int count = 0;
    for (int i = 0, x; i < n; ++i) {
        if (!(std::cin >> x)) {
            std::cerr << "Error\n";
            return 1;
        }
        if (x % 2 == 0) ++count;
    }
    std::cout << count << '\n';
    return 0;
}

```

#### Пример работы

Ввод:

```text
5
1 2 4 7 8
```

Вывод:

```text
3
```

#### Граничные случаи

Ноль считается чётным; отрицательные чётные числа также учитываются.

#### Компиляция и запуск

```bash
g++ -std=c++17 -Wall -Wextra -Wpedantic main.cpp -o program
./program
```
