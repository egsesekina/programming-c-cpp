### Задание 21. Массивы и арифметика указателей

**Условие.** Считать массив и с помощью арифметики указателей найти сумму, минимум и максимум его элементов.

#### Формат входных данных

N (1..1000), затем N целых чисел.

#### Формат выходных данных

сумма, минимум и максимум через пробел. Если входные данные нарушают указанный формат или ограничения, программа выводит `Error` в стандартный поток ошибок и завершается с ненулевым кодом.

#### Разбор решения

Встроенный массив C занимает непрерывный участок памяти. Перемещение указателя на один элемент переводит его к следующему значению, поэтому массив можно обработать без индексирования.

#### Алгоритм

1. проверить размер и считать массив.
2. установить сумму, минимум и максимум.
3. пройти от первого указателя до указателя за последним элементом.
4. вывести три результата.

#### Исходный код

[main.c](main.c)

```c
/*
 * Задание 21. Считать массив и с помощью арифметики указателей найти
 * сумму, минимум и максимум его элементов.
 * Ввод: N (1..1000), затем N целых чисел.
 * Вывод: сумма, минимум и максимум через пробел.
 * Пример: 5 / 4 -2 7 7 1 -> 17 -2 7.
 */
#include <stdio.h>

int main(void) {
    int values[1000];
    int n;

    if (scanf("%d", &n) != 1 || n < 1 || n > 1000) {
        fprintf(stderr, "Error\n");
        return 1;
    }
    for (int *p = values; p < values + n; ++p) {
        if (scanf("%d", p) != 1) {
            fprintf(stderr, "Error\n");
            return 1;
        }
    }

    long long sum = 0;
    int minimum = values[0];
    int maximum = values[0];
    for (const int *p = values; p < values + n; ++p) {
        sum += *p;
        if (*p < minimum) minimum = *p;
        if (*p > maximum) maximum = *p;
    }

    printf("%lld %d %d\n", sum, minimum, maximum);
    return 0;
}

```

#### Пример работы

Ввод:

```text
5
4 -2 7 7 1
```

Вывод:

```text
17 -2 7
```

#### Граничные случаи

Один элемент одновременно является минимумом и максимумом; отрицательные значения корректно входят в сумму.

#### Компиляция и запуск

```bash
gcc -std=c17 -Wall -Wextra -Wpedantic main.c -o program
./program
```
