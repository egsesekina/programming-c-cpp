### Задание 21. Арифметические операции

**Вопрос.** Считайте два целых числа и выведите сумму, разность и произведение.

**Правильный ответ:** программа должна выводить результат, соответствующий условию задачи.

**Листинг программы:**

```cpp
#include <iostream>

int main() {
    long long a, b;
    std::cin >> a >> b;
    std::cout << "Sum: " << a + b << '\n';
    std::cout << "Difference: " << a - b << '\n';
    std::cout << "Product: " << a * b << '\n';
    return 0;
}
```
