### Задание 28. Препроцессор C

**Условие.** Создать безопасно заключённый в скобки макрос SQUARE и использовать условную компиляцию для диагностического сообщения.

#### Формат входных данных

целое X, |X| <= 3037000499.

#### Формат выходных данных

квадрат X. Если входные данные нарушают указанный формат или ограничения, программа выводит `Error` в стандартный поток ошибок и завершается с ненулевым кодом.

#### Разбор решения

Макрос заключает параметр и всё выражение в скобки, поэтому приоритет операторов не искажает результат. Диапазон входа исключает переполнение, а блок `#ifdef DEBUG` компилируется только при заданном макросе `DEBUG`.

#### Алгоритм

1. проверить входной диапазон.
2. при сборке с `-DDEBUG` вывести диагностику.
3. развернуть макрос с корректными скобками.
4. вывести квадрат.

#### Исходный код

[main.c](main.c)

```c
/*
 * Задание 28. Создать безопасно заключённый в скобки макрос SQUARE и
 * использовать условную компиляцию для диагностического сообщения.
 * Ввод: целое X, |X| <= 3037000499.
 * Вывод: квадрат X.
 * Пример: -12 -> 144.
 */
#include <stdio.h>

#define SQUARE(value) ((value) * (value))

int main(void) {
    long long x;
    if (scanf("%lld", &x) != 1 || x < -3037000499LL || x > 3037000499LL) {
        fprintf(stderr, "Error\n");
        return 1;
    }
#ifdef DEBUG
    fprintf(stderr, "DEBUG: x=%lld\n", x);
#endif
    printf("%lld\n", SQUARE(x));
    return 0;
}

```

#### Пример работы

Ввод:

```text
-12
```

Вывод:

```text
144
```

#### Граничные случаи

Аргумент макроса не должен иметь побочных эффектов; ограничение диапазона гарантирует представимость квадрата.

#### Компиляция и запуск

```bash
gcc -std=c17 -Wall -Wextra -Wpedantic main.c -o program
./program
```
