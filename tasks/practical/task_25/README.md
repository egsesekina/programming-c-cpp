### Задание 25. Сумма натуральных чисел

**Вопрос.** Найдите сумму чисел от 1 до N с помощью цикла.

**Правильный ответ:** программа должна выводить результат, соответствующий условию задачи.

**Листинг программы:**

```cpp
#include <iostream>

int main() {
    int n;
    std::cin >> n;
    long long sum = 0;
    for (int i = 1; i <= n; ++i)
        sum += i;
    std::cout << sum << '\n';
    return 0;
}
```
