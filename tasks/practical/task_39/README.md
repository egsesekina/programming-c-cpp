### Задание 39. Главная диагональ матрицы

**Условие.** Найти сумму главной диагонали квадратной матрицы.

#### Формат входных данных

N (1..100), затем N*N целых чисел.

#### Формат выходных данных

сумма элементов a[i][i]. Если входные данные нарушают указанный формат или ограничения, программа выводит `Error` в стандартный поток ошибок и завершается с ненулевым кодом.

#### Разбор решения

Для суммы нужны только элементы с равными индексами строки и столбца. Матрицу можно обработать потоком, не сохраняя все `N*N` значений.

#### Алгоритм

1. проверить размер.
2. считать все элементы.
3. добавлять только элементы с `i == j`.
4. вывести сумму.

#### Исходный код

[main.cpp](main.cpp)

```cpp
/*
 * Задание 39. Найти сумму главной диагонали квадратной матрицы.
 * Ввод: N (1..100), затем N*N целых чисел.
 * Вывод: сумма элементов a[i][i].
 * Пример: 2 / 1 2 / 3 4 -> 5.
 */
#include <iostream>

int main() {
    int n;
    if (!(std::cin >> n) || n < 1 || n > 100) {
        std::cerr << "Error\n";
        return 1;
    }
    long long diagonalSum = 0;
    for (int i = 0; i < n; ++i) {
        for (int j = 0; j < n; ++j) {
            int x;
            if (!(std::cin >> x)) {
                std::cerr << "Error\n";
                return 1;
            }
            if (i == j) diagonalSum += x;
        }
    }
    std::cout << diagonalSum << '\n';
    return 0;
}

```

#### Пример работы

Ввод:

```text
2
1 2
3 4
```

Вывод:

```text
5
```

#### Граничные случаи

При неполной матрице печатается `Error`; хранить матрицу целиком не требуется.

#### Компиляция и запуск

```bash
g++ -std=c++17 -Wall -Wextra -Wpedantic main.cpp -o program
./program
```
