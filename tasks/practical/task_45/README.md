### Задание 45. Шаблон функции

**Условие.** Реализовать шаблон функции maxValue для сравнимых типов.

#### Формат входных данных

два целых числа и два вещественных числа.

#### Формат выходных данных

максимум целой пары и максимум вещественной пары на отдельных строках. Если ввод не читается или вещественное число неконечно, программа выводит `Error` в стандартный поток ошибок и завершается с ненулевым кодом.

#### Разбор решения

Параметр типа `T` позволяет одной реализации работать с `int`, `double` и другими сравнимыми типами. Параметры передаются по константной ссылке, чтобы избежать копирования крупных объектов.

#### Алгоритм

1. считать целую и вещественную пары.
2. инстанцировать шаблон для `long long` и `double`.
3. сравнить значения оператором `<`.
4. вывести максимумы.

#### Исходный код

[main.cpp](main.cpp)

```cpp
/*
 * Задание 45. Реализовать шаблон функции maxValue для сравнимых типов.
 * Ввод: два целых и два вещественных числа.
 * Вывод: максимум целой и максимум вещественной пары.
 * Пример: 3 8 / 2.5 1.7 -> 8 / 2.5.
 */
#include <cmath>
#include <iostream>

template <typename T>
T maxValue(const T& a, const T& b) {
    // Тип T должен поддерживать операцию сравнения.
    return (a < b) ? b : a;
}

int main() {
    long long first_integer, second_integer;
    double first_real, second_real;
    if (!(std::cin >> first_integer >> second_integer >>
          first_real >> second_real) ||
        !std::isfinite(first_real) || !std::isfinite(second_real)) {
        std::cerr << "Error\n";
        return 1;
    }
    std::cout << maxValue(first_integer, second_integer) << '\n';
    std::cout << maxValue(first_real, second_real) << '\n';
    return 0;
}

```

#### Пример работы

Ввод:

```text
3 8
2.5 1.7
```

Вывод:

```text
8
2.5
```

#### Граничные случаи

Тип `T` должен поддерживать `<`; для несравнимого типа ошибка возникнет при компиляции. Значения `NaN` и бесконечность отклоняются.

#### Компиляция и запуск

```bash
g++ -std=c++17 -Wall -Wextra -Wpedantic main.cpp -o program
./program
```
