### Задание 45. Шаблон функции

**Условие.** Реализовать шаблон функции maxValue для сравнимых типов.

#### Формат входных данных

отсутствует.

#### Формат выходных данных

8 и 2.5 на отдельных строках. Если входные данные нарушают указанный формат или ограничения, программа выводит `Error` в стандартный поток ошибок и завершается с ненулевым кодом.

#### Разбор решения

Параметр типа `T` позволяет одной реализации работать с `int`, `double` и другими сравнимыми типами. Параметры передаются по константной ссылке, чтобы избежать копирования крупных объектов.

#### Алгоритм

1. инстанцировать шаблон для `int`.
2. инстанцировать шаблон для `double`.
3. сравнить значения оператором `<`.
4. вывести результаты.

#### Исходный код

[main.cpp](main.cpp)

```cpp
/*
 * Задание 45. Реализовать шаблон функции maxValue для сравнимых типов.
 * Ввод: отсутствует.
 * Вывод: 8 и 2.5 на отдельных строках.
 * Пример запуска: program -> 8 / 2.5.
 */
#include <iostream>

template <typename T>
T maxValue(const T& a, const T& b) {
    // Тип T должен поддерживать операцию сравнения.
    return (a < b) ? b : a;
}

int main() {
    std::cout << maxValue(3, 8) << '\n';
    std::cout << maxValue(2.5, 1.7) << '\n';
    return 0;
}

```

#### Пример работы

Ввод:

```text
не требуется
```

Вывод:

```text
8
2.5
```

#### Граничные случаи

Тип `T` должен поддерживать `<`; для несравнимого типа ошибка возникнет при компиляции.

#### Компиляция и запуск

```bash
g++ -std=c++17 -Wall -Wextra -Wpedantic main.cpp -o program
./program
```
