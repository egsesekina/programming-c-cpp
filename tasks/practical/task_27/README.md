### Задание 27. Классы памяти в C

**Условие.** Продемонстрировать статическую длительность хранения: функция add хранит число вызовов, а файловая переменная — общую сумму.

#### Формат входных данных

N (0..1000), затем N целых чисел.

#### Формат выходных данных

итоговая сумма и число вызовов add. Если входные данные нарушают указанный формат или ограничения, программа выводит `Error` в стандартный поток ошибок и завершается с ненулевым кодом.

#### Разбор решения

Локальная переменная `calls` со спецификатором `static` сохраняет значение между вызовами. Файловая переменная `total` тоже имеет статическую длительность хранения, а `static` на уровне файла ограничивает связывание текущей единицей трансляции.

#### Алгоритм

1. считать число значений.
2. для каждого вызвать `add`.
3. накопить сумму в файловой переменной.
4. вывести сумму и сохранённое число вызовов.

#### Исходный код

[main.c](main.c)

```c
/*
 * Задание 27. Продемонстрировать статическую длительность хранения:
 * функция add хранит число вызовов, а файловая переменная — общую сумму.
 * Ввод: N (0..1000), затем N целых чисел.
 * Вывод: итоговая сумма и число вызовов add.
 * Пример: 3 / 5 -2 8 -> Sum: 11 / Calls: 3.
 */
#include <stdio.h>

static long long total = 0;

static unsigned int add(int value) {
    static unsigned int calls = 0;
    total += value;
    return ++calls;
}

int main(void) {
    int n;
    if (scanf("%d", &n) != 1 || n < 0 || n > 1000) {
        fprintf(stderr, "Error\n");
        return 1;
    }

    unsigned int calls = 0;
    for (int i = 0; i < n; ++i) {
        int value;
        if (scanf("%d", &value) != 1) {
            fprintf(stderr, "Error\n");
            return 1;
        }
        calls = add(value);
    }

    printf("Sum: %lld\nCalls: %u\n", total, calls);
    return 0;
}

```

#### Пример работы

Ввод:

```text
3
5 -2 8
```

Вывод:

```text
Sum: 11
Calls: 3
```

#### Граничные случаи

При `N = 0` сумма и число вызовов равны нулю.

#### Компиляция и запуск

```bash
gcc -std=c17 -Wall -Wextra -Wpedantic main.c -o program
./program
```
