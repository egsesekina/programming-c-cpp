### Задание 27. Максимум трёх чисел

**Вопрос.** Найдите наибольшее из трёх целых чисел.

**Правильный ответ:** программа должна выводить результат, соответствующий условию задачи.

**Листинг программы:**

```cpp
#include <algorithm>
#include <iostream>

int main() {
    int a, b, c;
    std::cin >> a >> b >> c;
    std::cout << std::max({a, b, c}) << '\n';
    return 0;
}
```
