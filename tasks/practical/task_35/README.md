### Задание 35. Функция нахождения НОД

**Условие.** Вычислить НОД двух неотрицательных целых чисел.

#### Формат входных данных

два значения типа long long, не оба равны нулю.

#### Формат выходных данных

наибольший общий делитель. Если входные данные нарушают указанный формат или ограничения, программа выводит `Error` в стандартный поток ошибок и завершается с ненулевым кодом.

#### Разбор решения

Алгоритм Евклида заменяет пару `(a, b)` на `(b, a % b)`. Остатки уменьшаются, а последнее ненулевое значение является НОД.

#### Алгоритм

1. проверить аргументы.
2. повторять деление с остатком до `b == 0`.
3. вернуть `a`.
4. вывести НОД.

#### Исходный код

[main.cpp](main.cpp)

```cpp
/*
 * Задание 35. Вычислить НОД двух неотрицательных целых чисел.
 * Ввод: два значения типа long long, не оба равны нулю.
 * Вывод: наибольший общий делитель.
 * Пример: 48 18 -> 6.
 */
#include <iostream>

// Алгоритм Евклида.
long long gcd(long long a, long long b) {
    while (b != 0) {
        long long remainder = a % b;
        a = b;
        b = remainder;
    }
    return a;
}

int main() {
    long long a, b;
    if (!(std::cin >> a >> b) || a < 0 || b < 0 || (a == 0 && b == 0)) {
        std::cerr << "Error\n";
        return 1;
    }
    std::cout << gcd(a, b) << '\n';
    return 0;
}

```

#### Пример работы

Ввод:

```text
48 18
```

Вывод:

```text
6
```

#### Граничные случаи

`gcd(0, b) = b`; пара `0 0` не имеет определённого НОД и отклоняется.

#### Компиляция и запуск

```bash
g++ -std=c++17 -Wall -Wextra -Wpedantic main.cpp -o program
./program
```
