### Задание 42. Класс и инкапсуляция

**Условие.** Реализовать инкапсулированный счётчик.

#### Формат входных данных

отсутствует.

#### Формат выходных данных

значение после двух вызовов increment, то есть 2. Если входные данные нарушают указанный формат или ограничения, программа выводит `Error` в стандартный поток ошибок и завершается с ненулевым кодом.

#### Разбор решения

Поле скрыто в закрытой части класса, поэтому внешний код меняет его только через `increment`. Метод чтения помечен `const`, так как не изменяет объект.

#### Алгоритм

1. создать счётчик.
2. дважды вызвать `increment`.
3. прочитать значение константным методом.
4. вывести результат.

#### Исходный код

[main.cpp](main.cpp)

```cpp
/*
 * Задание 42. Реализовать инкапсулированный счётчик.
 * Ввод: отсутствует.
 * Вывод: значение после двух вызовов increment, то есть 2.
 * Пример запуска: program -> 2.
 */
#include <iostream>

class Counter {
private:
    int value;

public:
    explicit Counter(int initial = 0) : value(initial) {}

    void increment() { ++value; }
    int getValue() const { return value; }
};

int main() {
    Counter counter;
    counter.increment();
    counter.increment();
    std::cout << counter.getValue() << '\n';
    return 0;
}

```

#### Пример работы

Ввод:

```text
не требуется
```

Вывод:

```text
2
```

#### Граничные случаи

Пример не принимает ввод; метод чтения можно вызывать у `const Counter`.

#### Компиляция и запуск

```bash
g++ -std=c++17 -Wall -Wextra -Wpedantic main.cpp -o program
./program
```
