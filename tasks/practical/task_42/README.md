### Задание 42. Класс и инкапсуляция

**Условие.** Реализовать инкапсулированный счётчик и изменить его по входным данным.

#### Формат входных данных

начальное целое значение от -1000000000 до 1000000000 и число увеличений от 0 до 1000000.

#### Формат выходных данных

итоговое значение счётчика. Если входные данные нарушают указанный формат или ограничения либо результат выходит за верхнюю границу, программа выводит `Error` в стандартный поток ошибок и завершается с ненулевым кодом.

#### Разбор решения

Поле скрыто в закрытой части класса, поэтому внешний код меняет его только через `increment`. Метод чтения помечен `const`, так как не изменяет объект.

#### Алгоритм

1. проверить начальное значение и число увеличений.
2. создать счётчик с заданным начальным значением.
3. вызвать `increment` указанное число раз.
4. прочитать значение константным методом и вывести результат.

#### Исходный код

[main.cpp](main.cpp)

```cpp
/*
 * Задание 42. Реализовать инкапсулированный счётчик.
 * Ввод: начальное значение и число вызовов increment (0..1000000).
 * Вывод: итоговое значение счётчика.
 * Пример: 5 3 -> 8.
 */
#include <iostream>

class Counter {
private:
    int value;

public:
    explicit Counter(int initial = 0) : value(initial) {}

    void increment() { ++value; }
    int getValue() const { return value; }
};

int main() {
    int initial;
    int increments;
    if (!(std::cin >> initial >> increments) || increments < 0 ||
        increments > 1000000 || initial > 1000000000 ||
        initial < -1000000000 || initial > 1000000000 - increments) {
        std::cerr << "Error\n";
        return 1;
    }

    Counter counter(initial);
    for (int i = 0; i < increments; ++i) counter.increment();
    std::cout << counter.getValue() << '\n';
    return 0;
}

```

#### Пример работы

Ввод:

```text
5 3
```

Вывод:

```text
8
```

#### Граничные случаи

Нулевое число увеличений допустимо; метод чтения можно вызывать у `const Counter`.

#### Компиляция и запуск

```bash
g++ -std=c++17 -Wall -Wextra -Wpedantic main.cpp -o program
./program
```
