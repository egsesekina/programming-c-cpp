### Задание 33. Поиск элемента

**Условие.** Найти индекс первого вхождения заданного числа в массив.

#### Формат входных данных

N (1..1000), N целых чисел и искомое число.

#### Формат выходных данных

индекс с нуля либо -1. Если входные данные нарушают указанный формат или ограничения, программа выводит `Error` в стандартный поток ошибок и завершается с ненулевым кодом.

#### Разбор решения

`std::find` выполняет линейный поиск и возвращает итератор первого совпадения. Если итератор равен `end`, элемента нет; иначе разность итераторов даёт индекс.

#### Алгоритм

1. считать и проверить массив.
2. считать искомое значение.
3. найти первое совпадение.
4. вывести индекс или `-1`.

#### Исходный код

[main.cpp](main.cpp)

```cpp
/*
 * Задание 33. Найти индекс первого вхождения заданного числа в массив.
 * Ввод: N (1..1000), N целых чисел и искомое число.
 * Вывод: индекс с нуля либо -1.
 * Пример: 5 / 8 3 8 1 0 / 8 -> 0.
 */
#include <algorithm>
#include <iostream>
#include <vector>

int main() {
    int n;
    if (!(std::cin >> n) || n < 1 || n > 1000) {
        std::cerr << "Error\n";
        return 1;
    }
    std::vector<int> a(n);
    for (int& x : a) {
        if (!(std::cin >> x)) {
            std::cerr << "Error\n";
            return 1;
        }
    }
    int target;
    if (!(std::cin >> target)) {
        std::cerr << "Error\n";
        return 1;
    }
    auto it = std::find(a.begin(), a.end(), target);
    std::cout << (it == a.end() ? -1 : int(it - a.begin())) << '\n';
    return 0;
}

```

#### Пример работы

Ввод:

```text
5
8 3 8 1 0
8
```

Вывод:

```text
0
```

#### Граничные случаи

Повторяющиеся значения дают индекс первого; отсутствие значения даёт `-1`.

```bash
g++ -std=c++17 -Wall -Wextra -Wpedantic main.cpp -o program
```
