# Программирование на C и C++

Учебный проект содержит 50 заданий по дисциплине «Программирование на C/C++»: теоретические вопросы с объяснениями, определения, анализ фрагментов и 38 самостоятельных программ. Задания охватывают все разделы программы, включая отдельные решения на C и темы продвинутого C++.

## Темы

- базовый синтаксис, типы, операции, условия и циклы;
- функции, ссылки, рекурсия и контроль переполнения;
- массивы и арифметика указателей в C;
- динамическая память `malloc` и `free`;
- строки `char[]` и функции `string.h`;
- файлы `FILE*`, `fopen`, `fscanf`, `fprintf` и `fclose`;
- `struct`, `union`, `enum` и односвязные списки;
- классы памяти и препроцессор C;
- классы, статические члены и перегрузка операторов C++;
- одиночное и множественное наследование, полиморфизм;
- пространства имён и именованные приведения типов;
- шаблоны, исключения, алгоритм Дейкстры и BFS;
- обработка строк UTF-8.

## Компиляция и запуск

Для C требуется компилятор с поддержкой C17, для C++ — поддержка C++17. Например, задание 21 собирается так:

```bash
cd tasks/practical/task_21
gcc -std=c17 -Wall -Wextra -Wpedantic main.c -o program
./program
```

Пример для задания 49:

```bash
cd tasks/advanced/task_49
g++ -std=c++17 -Wall -Wextra -Wpedantic main.cpp -o program
./program
```

В Windows PowerShell исполняемый файл запускается командой `./program.exe` или `.\program.exe`.

### Ввод UTF-8 в Windows

Задания 7, 37 и 38 ожидают UTF-8. Надёжный способ проверки — сохранить ввод в UTF-8-файле и перенаправить его программе:

```powershell
.\program.exe < input.txt
```

`std::string::size()` измеряет байты, поэтому задание 7 разбирает последовательности UTF-8 и считает кодовые точки. Задания 37 и 38 также работают с целыми UTF-8-последовательностями, а не переворачивают или сравнивают отдельные байты.

## Особенности отдельных программ

- задания 24 и 41 читают `input.txt` и создают `output.txt`;
- задание 36 обнаруживает переполнение `long long`, поэтому `3 40` приводит к `Error`;
- задание 43 отклоняет нулевые, отрицательные, бесконечные размеры и `NaN`;
- задание 46 имеет обе перегрузки `top()`: `T&` и `const T&`;
- задание 49 ожидает ровно `R × C` элементов. При неполном вводе интерактивная консоль ждёт недостающие данные, а после закрытия потока программа выводит `Error`; сам BFS не содержит бесконечного цикла.
