# Программирование на C/C++

Учебный репозиторий с практическими заданиями по дисциплине «Программирование на C/C++».

## О проекте

Репозиторий содержит решения учебных заданий, направленных на изучение основ программирования на C++: типов данных, операторов, условных конструкций, циклов, массивов, функций, строк, указателей, структур, файлов, классов, объектно-ориентированного программирования и основных алгоритмов.

**Цель проекта:** закрепить теоретические знания и получить практические навыки разработки, тестирования и документирования программ.

## Используемые технологии

- Язык программирования: C++.
- Стандарт языка: C++17.
- Компилятор: GCC или совместимый компилятор C++17.
- Среда разработки: Visual Studio Code, CLion, Visual Studio или другая среда с поддержкой C++.
- Система контроля версий: Git.
- Хранение исходного кода: GitHub.

## Требования для запуска

Для компиляции программ необходим компилятор C++ с поддержкой стандарта C++17.

Проверить наличие компилятора GCC можно командой:

```bash
g++ --version
```

Если компилятор установлен, команда выведет информацию о его версии.

## Как получить проект

Склонируйте репозиторий:

```bash
git clone https://github.com/egsesekina/programming-c-cpp.git
```

Перейдите в каталог проекта:

```bash
cd programming-c-cpp
```

## Структура репозитория

- `tasks/closed/` — закрытые вопросы и правильные ответы.
- `tasks/combined/` — комбинированные задания с объяснениями и примерами.
- `tasks/definitions/` — определения основных терминов.
- `tasks/practical/` — практические задания с исходным кодом.
- `tasks/advanced/` — задания повышенной сложности.

В папках программных заданий размещаются файл `main.cpp` и описание `README.md`.
